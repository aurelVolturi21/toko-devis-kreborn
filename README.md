# TOKO × K-Reborn — Devis interactif

Stack :
- HTML5
- Tailwind CSS CDN
- JavaScript vanilla
- Lucide Icons CDN
- Google Fonts CDN

## Structure

```text
toko-devis-kreborn/
├── index.html
└── assets/
    └── (logo K-Reborn à ajouter)
```

## À personnaliser avant livraison

1. Remplacer le bloc logo temporaire dans `index.html` par le vrai SVG K-Reborn.
2. Remplacer `229XXXXXXXX` par le numéro WhatsApp réel de K-Reborn.
3. Vérifier les montants et textes.
4. Tester les deux liens WhatsApp.
5. Tester mobile/tablette/desktop.
6. Déployer le dossier sur Surge.

## Déploiement Surge

```bash
npm install --global surge
cd toko-devis-kreborn
surge
```

Puis choisir le domaine Surge souhaité.
